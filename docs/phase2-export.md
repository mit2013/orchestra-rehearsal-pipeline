# アマオケ練習録音 自動編集パイプライン ― フェーズ2: 曲目単位エクスポート & タグ埋め込み

## 0. 位置づけ
正規化・ミックス・レコーダプロファイル抽象化(前指示書)は260802・260726の2データセットで実装・検証・試聴まで完了済み。本指示書は、`trimmed/`配下の`_final.wav`(ミックス済み最終音源)を、配布用のWAV(32bit float)とMP3(320kbps、タグ付き)に書き出す工程を実装する。

**スコープ外(次フェーズ以降)**:
- 曲・楽章単位でのさらなる分割(1合奏ブロック=1トラックとする方針に確定)
- 無音部・指揮者の発言をカットした「忙しい人向け」ダイジェスト版の作成
- Google Drive / Boxへのアップロード、共有リンク生成
- Facebook Messengerへの通知文言生成

**制約**: `trimmed/`配下の既存ファイル(`_ext.wav`, `_int.wav`, `_norm.wav`, `_final.wav`)は読み取り専用として扱い、本指示書の実装で変更・削除しないこと。

## 1. ブロックの曲名(トラックタイトル)自動採番ルール
合奏ブロック数に応じて、以下のルールでタイトルを決定する。

| ブロック数 | タイトル |
|---|---|
| 2(休憩1回) | 前半 / 後半 |
| 3(休憩2回) | 前半 / 中盤 / 後半 |
| それ以外(1、4以上) | コマ1 / コマ2 / コマ3 ... |

ブロック数は`confirmed.json`で`action: keep`となっている区間の数から判定する。

## 2. タグ情報の決定ルール
| タグ | 値 | 由来 |
|---|---|---|
| アルバム名 | 日付文字列そのもの(例: `260802`) | `--date`引数 |
| 曲タイトル | 上記§1のルールによる自動採番 | ブロック順序 |
| アルバムアーティスト | オーケストラ名(設定ファイル由来) | §3参照 |
| 曲アーティスト | 同上 | 同上 |
| トラック番号 | ブロックの通し番号(1, 2, 3...) | ブロック順序 |
| 年 | 日付文字列から導出(例: `260802`→`2026`) | `--date`引数(先頭2桁+`20`) |

## 3. オーケストラ名のデフォルト設定
プロジェクト直下に`pipeline_defaults.json`を新設する:

```json
{
  "orchestra": "Windrose Sinfonie Orchester"
}
```

- `ingest`実行時、この値を`session_config.json`に`orchestra`としてコピーする(初回のみ。既に値がある場合は上書きしない)
- 「ある時期は単一のオーケストラの練習が続く」という運用のため、`pipeline_defaults.json`を書き換えれば以降の新規`ingest`から反映される。特定の日付だけ別団体にしたい場合は、その日付の`session_config.json`の`orchestra`を直接編集すればよい(既存の`ext_lr_map`等と同じ上書きパターン)
- `pipeline_defaults.json`が存在しない場合のフォールバックのデフォルト値も`"Windrose Sinfonie Orchester"`とする

## 4. エクスポート処理
- 対象: `trimmed/{idx}_合奏{idx}_final.wav`(ミックス済み最終音源。`source=ext_only`ならext系統のみが実体)
- WAV出力: 32bit float のまま、コンテナ変換のみ(再エンコードしない)。`_final.wav`が既に正しい形式であれば、実質的にコピー+リネームでよい
- MP3出力: ffmpegの`libmp3lame`、ビットレート**320kbps**固定
- タグ埋め込み: MP3にのみ適用(WAVはタグ埋め込み不要)。`mutagen`を使い、以下のID3フレームを設定する
  - `TALB`(アルバム) = §2のアルバム名
  - `TIT2`(タイトル) = §2の曲タイトル
  - `TPE2`(アルバムアーティスト) = §2のアルバムアーティスト
  - `TPE1`(アーティスト) = §2の曲アーティスト
  - `TRCK`(トラック番号) = §2のトラック番号
  - `TDRC`または`TYER`(年) = §2の年
- 出力先: `output/{date}/export/`
- ファイル名: `{date}_{タイトル}.wav`、`{date}_{タイトル}.mp3`(例: `260802_前半.wav`, `260802_前半.mp3`)

## 5. CLIコマンド
```bash
python pipeline.py export --date 260802
```
(`normalize`・`mix`が未実行の場合はエラーで止め、先に実行するよう促すこと)

## 6. 検証してほしいこと
- WAV出力が`_final.wav`とサンプル単位で一致すること(sha256またはサンプル差分で確認)
- MP3のタグを`mutagen`で読み戻し、§2の期待値と一致することを確認すること(書き込んだ値が本当に反映されているかを実測する)
- 260802(2ブロック→前半/後半)・260726(3ブロック→前半/中盤/後半)の両方で実行し、ファイル名・タグが期待通りになることを確認すること
- `pipeline_defaults.json`を変更してから新しい日付で`ingest`した場合に、新しいオーケストラ名が反映されること(合成データでよい)。既存日付の`session_config.json`が上書きされないことも確認すること
